# vachanamrut-concordance
Vachanamrut nondh by Ashwin Babubhai Shah ( nathji Mandal )

**Live site: https://hardyshah.github.io/vachanamrut-concordance/**

**Satsang Library: https://hardyshah.github.io/vachanamrut-concordance/library.html** — the Vachanamrut, Vachanamrut Nondh, Shrimad Bhagwat, Ashtako ane Kirtano, Nimit Matra, Amrutvarsha, Satsang Prabha and the Smruti Ank, to read or download.

A searchable word index of the Gujarati Vachanamrut. You can search in Gujarati or romanized spelling ("ishvar", "akshar"), see every occurrence in context with its page, and read each Vachanamrut. It also has a glossary and a bibliography of the scriptures cited.

It includes the **Vachanamrut Nondh compiled by Ashwin Babubhai Shah**, with special guidance / inspiration from Nathji Mandal and (Bhaiji Dada and Dadaji): 5,583 topics with references and quotations, 13 appendices and an index of parables, cross-linked with the text.
