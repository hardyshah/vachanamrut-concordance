# vachanamrut-concordance
Vachanamrut nondh by Ashwin Babubhai Shah ( nathji Mandal )

**Live site: https://hardyshah.github.io/vachanamrut-concordance/**

A searchable word index of the Gujarati Vachanamrut. You can search in Gujarati or romanized spelling ("ishvar", "akshar"), see every occurrence in context with its page, and read each Vachanamrut. It also has a glossary and a bibliography of the scriptures cited.

It includes the **Vachanamrut Nondh compiled by Ashwin Babubhai Shah**: 5,583 topics with references and quotations, 13 appendices and an index of parables, cross-linked with the text.
